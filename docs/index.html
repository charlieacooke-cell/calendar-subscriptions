How to subscribe

  1. Copy a feed's link address (right-click → Copy Link).
  2. Apple Calendar: File → New Calendar Subscription, paste, set auto-refresh to every day.
  3. Google Calendar: Other calendars → + → From URL, paste.
  4. Outlook: Add calendar → Subscribe from web, paste.

Swap https:// for webcal:// to have your calendar app pick the link up directly.
